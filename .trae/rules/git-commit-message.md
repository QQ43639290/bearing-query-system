## 提交信息规范

### 格式要求
- 使用中文编写提交信息
- 首行简明描述主要变更（不超过50字）
- 空一行后详细说明变更内容和原因
- 如果有影响范围需要说明（如：影响价格查询功能）

### 变更类型标识
- ✨ 新功能
- 🐛 修复bug
- 📊 数据更新
- 🎨 UI/样式调整
- ⚡ 性能优化
- 📝 文档更新
- 🔧 配置修改
- 🚀 部署相关

### 自动生成规则
1. 分析所有变更文件的扩展名和内容
2. 识别变更类型和影响范围
3. 生成简洁的提交标题
4. 在正文中详细说明变更内容
5. 如果涉及多个功能模块，需要分行说明
